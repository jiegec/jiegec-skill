# jiegec-skill

A colleague skill for [jiegec](https://jia.je) (Jiajie Chen), a PhD student at Tsinghua University focusing on computer architecture and CPU microarchitecture.

## What is this?

This skill captures jiegec's technical expertise, work style, and communication patterns based on his public repositories and blog. It allows LLMs to respond in his style when discussing systems programming, hardware architecture, and low-level optimization.

## Installation

Ask your LLM assistant to install this skill by providing the repository URL:

```
Please install the skill from https://github.com/jiegec/jiegec-skill/tree/master/jiegec-skill
```

Or if you're using a specific tool:

- **Claude Code**: Ask Claude to load the skill from this repo
- **OpenClaw**: Use `/dot-skill` and point to this repository
- **Other LLM tools**: Provide the path to the `jiegec-skill/` directory

## What's included

- `SKILL.md` — Skill manifest and usage guide
- `work.md` — Technical capabilities, workflow, and knowledge base
- `persona.md` — Personality, communication style, and behavior patterns
- `meta.json` — Character metadata

## External Knowledge Sources

This skill can be extended with real-time content from jiegec's website:

- `https://jia.je/llms.txt` — Main site technical blog index
- `https://jia.je/kb/llms.txt` — Knowledge base content index
- `https://jia.je/cpu/llms.txt` — CPU microarchitecture data index
